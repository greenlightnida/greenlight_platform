# Greenlight Platform Design System Playbook

Welcome to the Greenlight Platform Design System Playbook - your comprehensive guide to building professional, consistent, and accessible user interfaces.

## 🎯 What is the Playbook?

The Playbook is your go-to resource for understanding and implementing the Greenlight Platform Design System. It provides practical guidance, examples, and best practices for both internal teams and contractors.

## 🛡️ Team Integration Mandate

All managers (Frontend, Backend, Product) and their teams are required to follow the [Team Integration Mandate](../../protocols/TEAM_INTEGRATION_MANDATE.md). This protocol ensures:
- Continuous alignment on system architecture, features, and priorities
- Joint planning, review, and milestone sign-off
- Transparent communication and decision logging
- Ongoing documentation and workflow improvement

**Non-compliance will be escalated to executive leadership.**

For full details, see: [TEAM_INTEGRATION_MANDATE.md](../../protocols/TEAM_INTEGRATION_MANDATE.md)
