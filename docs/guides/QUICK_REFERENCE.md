## 🔄 **Quick Commands**

### **Switch Between Platforms:**
```bash
# Greenlight (main platform)
npm run launch    # Launch protocol
npm run wrap      # Wrap protocol  
npm run anchor    # Anchor command

# Top Bins platform
cd top-bins-platform
npm run dev       # Start dev server
npm run build     # Build for production
```

### **Search Everything:**
- `Cmd+Shift+F` → Search across all platforms
- `Cmd+P` → Quick file finder

## 🆘 **Common Scenarios**

### **"I want to work on Top Bins only":**
1. Click "⚽ Top Bins Platform" in sidebar
2. Or: File → Open Folder → `top-bins-platform`

### **"I need to search across everything":**
1. `Cmd+Shift+F`
2. Type your search term
3. Results show from all platforms

### **"I want to run commands for both platforms":**
1. Open terminal in Greenlight folder
2. Open new terminal in Top Bins folder
3. Run commands in parallel

### **"I got lost in the file structure":**
1. `Cmd+Shift+P` → "File: Open Recent"
2. Or close workspace and reopen: `cursor Greenlight_MultiPlatform_Workspace.code-workspace`
